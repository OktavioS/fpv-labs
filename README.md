# fpv-labs

Репозиторій лабораторних робіт з дисципліни «Програмно-апаратне забезпечення систем рухомих об'єктів».

Кожна лабораторна — окрема папка в `src/`.

## src/fpv_lab2 — Моделювання безпілотних систем у Gazebo та ArduPilot SITL

ROS2-пакет (`ament_python`) з вузлом автоматичного тестового польоту дрона (ArduPilot SITL +
Gazebo Harmonic + ROS 2 Humble, симуляція в WSL2). Вузол проходить весь цикл: очікування
готовності системи → GUIDED → армування → зліт → зависання → політ до цільової точки за
індивідуальним варіантом → посадка.

Запуск: `ros2 run fpv_lab2 flight_test` (симуляція запускається окремо, `~/ardu_ws/scripts/start_sim.sh`).
