# fpv-labs

Репозиторій лабораторних робіт з дисципліни «Програмно-апаратне забезпечення систем рухомих об'єктів».

Кожна папка в репозиторії відповідає одній лабораторній роботі — назва папки вказує, до якої
лаби вона належить. Опис, інструкції та деталі кожної конкретної лабораторної — у README.md
всередині її папки.

## Лабораторні роботи

- `src/fpv_lab2` — Лабораторна №2: Моделювання безпілотних систем у Gazebo та ArduPilot SITL
- `lab9` — Лабораторна №9: Проєктування і 3D-друк компонентів FPV-систем (Autodesk Fusion)
